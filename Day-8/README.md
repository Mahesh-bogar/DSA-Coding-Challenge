# Day 8 - Count Elements With Maximum Frequency (LeetCode #3005)

## 🧠 Problem
Return the total frequencies of elements that have the maximum frequency.

## 🚀 Approach
1. Count frequency of each element using HashMap  
2. Find maximum frequency  
3. Add frequencies of elements having max frequency  

## 📊 Example

Input:  
[1,2,2,3,1,4]

Frequency:  
1 → 2  
2 → 2  
3 → 1  
4 → 1

Maximum Frequency = 2

Output: 4

## 💡 Key Learning
- Frequency counting using HashMap  
- Finding maximum value  
- Efficient iteration through map

## ⏱ Time Complexity
O(n)
