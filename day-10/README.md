# Day 11 - To Lower Case (String Manipulation)

## 🧠 Problem
Convert all uppercase letters in a string to lowercase.

---

## 🚀 Approach
- Used Java's built-in method `toLowerCase()`  
- It automatically converts uppercase letters to lowercase  

---

## 📊 Example

Input:  
"Hello"  

Output:  
"hello"  

Input:  
"LOVELY"  

Output:  
"lovely"  

---

## 💡 Key Learning
- Built-in methods simplify coding  
- Clean and readable code is important  
- Efficient string handling in Java  

---

## ⏱ Time Complexity
O(n)
