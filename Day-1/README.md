# Day 1 - Array Rotation (Reversal Algorithm)

## 🧠 Problem
Rotate an array to the left by ‘d’ positions efficiently.

## 🚀 Approach
Used the Reversal Algorithm instead of shifting elements one by one:

1. Reverse first `d` elements  
2. Reverse remaining elements  
3. Reverse the entire array  

## 📊 Example
Input:  
[1, 2, 3, 4, 5], d = 2  

Output:  
[3, 4, 5, 1, 2]

## 💡 Key Learning
- Optimized solution from **O(n*d) → O(n)**  
- Importance of breaking problems into smaller steps  
- Learned in-place array manipulation  

## ⏱ Time Complexity
O(n)
