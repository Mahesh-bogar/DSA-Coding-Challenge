# Day 18 - Best Time to Buy and Sell Stock

## Approach
Track minimum price and calculate profit.

## Explanation
- Traverse array once  
- Keep track of minimum price  
- Calculate profit = current price - minimum price  
- Update maximum profit  

## Example
Input: [7,1,5,3,6,4]  
Output: 5  

Input: [7,6,4,3,1]  
Output: 0  

## Time Complexity
O(n)
